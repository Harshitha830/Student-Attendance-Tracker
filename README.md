# 🎓 Student Attendance Tracker

A frontend web application for managing student attendance in schools and colleges.

## 🔗 Live Demo
[View on GitHub Pages](https://YOUR-USERNAME.github.io/student-attendance-tracker/)

## 📄 Pages
- **Login** – Role-based login (Admin / Teacher / Student)
- **Dashboard** – Stats cards, pie chart, monthly trend, overview table
- **Students** – Student list with search, filter, add student
- **Mark Attendance** – Present / Absent / Leave toggle per student
- **Reports** – Monthly report card with subject-wise breakdown
- **Parent Notify** – Send monthly report to parents via Email / SMS / WhatsApp

## ✨ Features
- Role-based login (Admin, Teacher, Student)
- Dashboard with attendance charts
- Mark attendance with P / A / L toggle
- Monthly attendance report per student
- Subject-wise attendance breakdown
- Low attendance alerts (below 75%)
- Send monthly report directly to parents
- Notification log
- Exam eligibility warning
- Responsive design

## 🛠 Tech Stack
- HTML5, CSS3, JavaScript
- Chart.js (for charts)
- No frameworks – pure frontend

## 🚀 How to Run
Just open `index.html` in any browser. No setup needed.

## 📦 Deploy on GitHub Pages
1. Push this folder to a GitHub repository
2. Go to Settings → Pages
3. Set source to `main` branch, `/ (root)`
4. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`
